Claude Code 설치 준비

강의 전에 한 번만 하면 됩니다. 순서대로 따라 하면 약 20~30분 걸려요. 관리자 권한이 있는 컴퓨터에서 해 주세요.

1Python

AI가 엑셀, PDF 같은 파일을 다룰 때 쓰는 엔진이에요.

  1. python.org/downloads에 들어갑니다.
  2. 노란 「Download Python 3.x」 버튼 위에 있는 「Python install manager」 버튼으로 받습니다(.msix 파일).
  3. 받은 파일을 열고 「설치」를 누릅니다.
  4. 검은 창이 뜨며 영어로 [y/N]을 묻습니다. 아래 표대로 답하세요.
화면에 나오는 질문답
Open Settings now?그냥 Enter
Update setting now? (긴 파일 경로)Y + Enter
Open Installed apps now?그냥 Enter
Add commands directory to your PATH now?Y + Enter
Install CPython now? (파이썬 본체)Y + Enter
View online help?답하지 말고 창 닫기 (설치 끝)

질문이 몇 개만 나오거나 아예 안 나와도 정상이에요. 모르면 전부 Y로 답해도 안전해요.

  1. python.org/downloads에서 노란 「Download Python 3.x」 버튼으로 .pkg를 받습니다.
  2. 받은 파일을 열고 「계속」, 「동의」, 「설치」를 누릅니다.
  3. 끝나고 열리는 폴더에서 「Install Certificates.command」를 더블클릭해 한 번 실행합니다.

설치해도 바탕화면에 아이콘이 생기지 않아요. 정상이에요.

2Node.js

Claude Code를 설치하고 돌리는 엔진이에요.

  1. nodejs.org에서 초록색 「Get Node.js」를 누릅니다(LTS 버전).
  2. 가운데 나오는 명령어 상자는 건드리지 말고, 아래로 내려 「Windows 설치 프로그램 (.msi)」「macOS 설치 프로그램 (.pkg)」을 받습니다.
  3. 받은 파일을 열고 기본값 그대로 「다음」을 눌러 설치합니다. 권한을 물으면 「예」.

3Git

작업 기록을 저장하는 도구예요. Claude Code가 안에서 씁니다.

  1. git-scm.com/download/win에서 「Click here to download」를 누릅니다.
  2. 받은 파일을 열고 옵션은 바꾸지 말고 계속 「Next」, 마지막에 「Install」.
  1. Spotlight(⌘ + 스페이스)에서 「터미널」을 열고 아래를 붙여 넣고 Enter.
xcode-select --install
  1. 창이 뜨면 「설치」를 누르고 끝날 때까지 기다립니다. 이미 설치돼 있다는 문구가 나오면 그대로 다음으로.
여기서 컴퓨터를 한 번 재부팅하세요. 그래야 1~3번 설치가 완전히 반영돼요.

4VS Code

파일을 보며 AI와 일하는 작업 화면이에요.

  1. code.visualstudio.com에서 받습니다. 버튼이 macOS로 보이면 「other platforms」에서 Windows x64 User Installer를 고르세요.
  2. 설치 옵션에서 「Code(으)로 열기」 두 개와 「PATH에 추가」가 체크돼 있는지 확인하고 설치합니다.
  3. 받은 zip을 풀고 나온 Visual Studio Code를 「응용 프로그램」 폴더로 옮깁니다.

5터미널 열기

명령어를 붙여 넣는 창이에요.

  1. Windows 키를 누르고 「PowerShell」을 검색해 「Windows PowerShell」을 엽니다.
  2. 붙여넣기는 Ctrl+V 또는 마우스 오른쪽 클릭이에요.
  1. ⌘ + 스페이스로 「터미널」을 검색해 엽니다.
  2. 붙여넣기는 ⌘ + V예요.

6Claude Code

터미널에 아래를 붙여 넣고 Enter. 1~3분, 길면 더 걸려요. 글자가 흘러가다 입력 줄이 다시 나오면 끝이에요.

npm install -g @anthropic-ai/claude-code

「스크립트를 실행할 수 없으므로」(about_Execution_Policies) 오류가 나오면 아래를 붙여 넣고 Enter, 물으면 Y를 누른 뒤 위 명령을 다시 실행하세요. 관리자 권한은 필요 없어요.

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

회사 정책으로 막히면 PowerShell 대신 「명령 프롬프트」를 열고 설치 명령만 입력하세요.

「EACCES」(권한) 오류가 나오면 앞에 sudo를 붙여 다시 실행하고, 맥 로그인 비밀번호를 입력하세요(입력해도 글자가 안 보이는 게 정상).

sudo npm install -g @anthropic-ai/claude-code
설치가 끝나면 터미널을 완전히 닫았다가 다시 여세요. 그래도 claude가 인식되지 않으면 재부팅하세요.

7설치 확인

새 터미널에서 하나씩 입력해 버전 숫자가 나오면 성공이에요. 숫자는 예시와 달라도 됩니다.

python --version
python3 --version
node -v
git --version
claude --version

네 개 모두 숫자가 나오면 준비 끝. 강의 당일 터미널에 claude를 입력하고 Claude 계정으로 로그인하면 바로 씁니다.

?막힐 때

  1. 「인식되지 않습니다」, 「command not found」: 터미널을 닫고 새로 열기 → 그래도 안 되면 재부팅 → 그래도 안 되면 해당 단계 다시.
  2. 관리자 권한이 없어 설치가 막힘: 회사 IT 담당자에게 요청하거나 개인 노트북으로 준비해 주세요.
  3. 회사 보안 프로그램이 막음: python.org, nodejs.org, git-scm.com, code.visualstudio.com, npmjs.com, claude.ai 접속이 열려 있어야 해요.
